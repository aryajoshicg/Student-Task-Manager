# Student-Task-Manager
📌 Project Overview

The Student Task Management System is a platform designed to help students organise, manage and track their academic tasks efficiently. It provides a centralised space where students can create tasks, set deadlines, prioritise assignments and monitor their progress.

The main objective is to improve students' productivity, time management and academic organisation.

🎯 Objectives

Simplify academic task management.

Help students prioritise assignments and activities.

Track task deadlines and completion status.

Improve time management and productivity.

Reduce the chances of missing important academic deadlines.
